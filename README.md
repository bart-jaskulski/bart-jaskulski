# Bartek Jaskulski

I build software in PHP, TypeScript and occasionally Go. Tech lead @ WP Desk.

Outside work, I’m building [picknext.games](https://picknext.games/) because it's not worth to keep up with 1.5k game releases a month, while only a handful really makes you want to play. And I want to gather them all, present to you, and allow to discover, powered by small recommendation engine that hopefully hits better than Steam game discovery feature (really, that one always felt disjointed to me).

[Tildom](https://tildom.app/) started because I lost all my saved links. I hadn’t backed up my server. Now the data lives locally on my devices, with offline access and sync between them. It’s grown into a few personal apps I use, built around SQLite in the browser—a concept I like playing with.
