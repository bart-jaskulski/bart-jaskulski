# AI search

There currently two interesting tools, when it comes to AI search engine: Phind
and Perplexity.

The first one is positioned as coder's tool, and the functionality to chat with
search is great for debugging and followup questions. Unfortunately, regular
search with followup question doesn't keep a reference in memory. Additionally,
they recently became aggressive about advertising pro features (yup, still using
free version). I haven't been using it yet, but you can also add a part of
"system-like" prompt, to force model to particular tone or so.

On the other hand, Perplexity is recommended by more users. At first I was
thinking of using it only for regular search, not code related, but possibly
their model surpasses Phind (although it messes with code formatting).
Perplexity has similar customization availability as Phind, for providing
user-defined rules, but there's additional feature, I've just found out:
collections. Besides simple organization of your search, you can also add custom
prompt, which will apply to all threads started in a specific collection.
