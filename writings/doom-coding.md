# Doom coding

Haven't been long since my [declaration not to use mobile agents](../mobile-agents.md), when I broke out and started to SSH into my always-on Mac.

I still don't like the idea, and the name: [doom-coding](https://github.com/rberg27/doom-coding). But I followed the setup and now can ping my codex or whatever to write thousands of lines of code when I walk the dogs... I'm feeling bad about this, though I felt even worse about the idea of the passing time. Constantly subjected to the sensation of subproductivity, while bursting with ideas.

I don't like the fact that I don't author the code by hand; that I only briefly understand how my features behave; that the bottleneck shifted from writing to verifying. It brings me to square one with low volume of deployments because I urge myself to supervise every change; I stand obliged to it, if I want to push to production.

I don't know if it's better that I can code from anywhere... At least I feel a bit more productive, with any vision at all of progressing in a good direction about some projects I've been dragging along.
